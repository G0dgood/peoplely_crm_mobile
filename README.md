# Outcess CRM Mobile
Expo/React Native mobile application for Outcess CRM

## Features
- Disposition Management
- Customer Book
- Team Members
- Realtime Updates
- Leaderboard
- Offline Support

## Tech Stack
- Expo
- React Native
- TypeScript
- Redux Toolkit / RTK Query
- Socket.io

## Installation
```bash
npm install
```

## Run
```bash
npx expo start
```
